# 教学班、实验任务与报告流程

本次整理采用“账号身份、教学班成员、实验分配、实操记录、报告提交”分别管理的方式。参考 Moodle 的分组与作业提交机制、Open edX 的学生任务入口；页面和代码按本项目重新实现，没有复制其源码。

参考：
- https://github.com/moodle/devdocs/blob/main/docs/apis/subsystems/group/index.md
- https://github.com/moodle/moodle/tree/main/public/mod/assign
- https://github.com/openedx/frontend-app-learner-dashboard

## 班级和学生

- 学号对应一个学生账号。同名不是同一个账号的依据。
- 一个账号可以加入多个教学班，导入另一班不会覆盖原账号的行政班、密码或已有记录。
- 导入已有学号时核对姓名与学生身份，避免把两个学生误合并。
- 旧实操记录缺少班级时，优先按已保存的实验分配班级归组；分配也未保存班级且账号只有一个班级时，按该班级归组。归属不明确时保留“未分班”，不推测跨班归属，也不改写原始实操记录。学情、报告列表及教师访问校验采用同一规则。
- 教师选择实验后，默认按班级展示权限范围内全部班级。学情、学生管理、报告列表各自搜索班级、学号或姓名，互不影响；不再设置全局教学班过滤或记忆上次班级。
- 学生管理默认包含未分配本实验的学生；批量分配按所选班级分别提交，同一账号同时在多个班级勾选时先提示选择一个班级。跨班批量操作发生部分失败时明确显示已分配数量，不声明全部成功。
- 实验分配保存所属教学班，实操记录使用此班级快照，而非学生客户端提交的班级名称。
- 现有教师账号的班级权限继续生效：指定管理班级的教师不能访问其他班级，未指定管理班级的教师沿用原有全班管理权限。

## 任务队列

- 教师可以提前分配多个实验。未完成实操的实验按分配时间、分配记录 ID 排队；已有进行中的实验优先。
- 学生继续使用原有实验台和顶部图标导航，登录后进入当前实验；实验下拉仅包含当前任务与已结束实验，不开放后续排队任务。必做仿真完成后才能通过页面进入实验台。
- 后端校验新实操与仿真完成是否属于当前任务，直接改链接不会绕过队列。
- 实操结束即让出当前任务位置，旧实验的报告未提交不阻塞下一个实验。
- 有实操记录的分配不能直接移除，以保留数据、报告和教师成绩；尚未开始的后续任务可以移除。
- 本版本延续每位学生每个实验一份进度和报告的模型。同一实验不能跨教学班重复分配；跨学期重修、同一实验多轮考核需要后续引入独立教学任务/轮次 ID，不能直接复用旧进度。

## 报告

- “实操已结束”和“报告已提交”是两个状态，教师统计不混用。
- 只有已结束且属于本人的对应实验记录才能保存报告草稿或正式提交。
- 草稿自动保存到服务器，并保留浏览器本地副本。服务器保存失败时明确提示“仅本机保存”。
- 报告中心列出待提交、已提交和已批改报告；学生可离开实验室后继续提交。设置截止时间后，逾期显示提醒但仍允许提交。
- 正式提交后的正文只读。重复提交为幂等操作，不覆盖正文、不清空教师评分；报告导出也不会改写已提交正文。
- 教师报告预评使用Workflow，结束输出仅为百分制 `score` 与评语 `comment`；新预评和教师批改按100分制保存。历史10分制成绩保留原始分及分制标记，接口统一显示百分制，不直接批量乘10改写旧记录。
- 教师按实验、教学班和提交状态查看名单。未提交的学生不展示为空白“已交报告”；同一学生不同实验的报告不会合并成一份。
- 当前不包含撤回、退回重交、报告版本比较；这些需要独立的版本和审核状态，不能通过静默覆盖已批改报告实现。

## 实验步骤

标准步骤、数据字段和校验规则由平台内置，教师不必从头编写。分配实验时可增加本班补充要求与报告截止时间；补充要求在学生当前任务上展示。更换仪器或实验方法时应先维护平台实验配置，确保步骤、仿真和数据校验相互一致。

## 兼容与验证

数据库只新增教学班成员表和分配元数据字段，保留现有账号、进度、实操与报告。旧账号的班级作为默认成员关系继续展示。自动化集成测试使用独立内存数据库，验证跨班导入、单一当前任务、提前进入限制、报告跨设备草稿、班级权限、报告归档与评分不被覆盖。

## 页面兼容

保留原有页面布局、配色、顶部 Tab 图标和导航位置。教师学情与报告继续采用原有班级分组卡片，搜索放在各自列表内；学生管理按班级分组显示，分配设置默认折叠。学生报告入口保留原有图标，进入待提交报告列表后使用原报告编辑页面。

教师端的实验选择移至顶部导航下方的内容区，选项来自内置实验配置；不根据测试账号的历史记录生成实验选项。学生卡片显示学号和班级，学生管理列表的“班级”列显示名册中的班级信息。

实验室、工位视频及教师手动绑定学生的当前流程见 [实验室部署说明](lab-deployment.md)。工位绑定只标记当前座位，不作为到课或实验完成的证明；课次排课、教师实操验收、报告退回重交和模板版本快照尚未实现。本文“任务队列”描述的是当前实现，不代表完整排课方案。
