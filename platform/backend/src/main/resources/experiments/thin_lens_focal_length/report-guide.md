# 薄透镜焦距测量报告要求

## Knowledge

- 本版本采用凸薄透镜实物实像的共轭法，u、v 均按正距离记录，1/f=1/u+1/v，f=uv/(u+v)。透镜中心作为薄透镜主平面近似。可用位移法复核：物屏间距 L>4f，两次清晰成像位置相距 D 时 f=(L²−D²)/(4L)。
- 报告保留原始测量表格、单位、数据处理过程、重复测量结果和误差分析；说明实际采用的方法与仪器参数。
- AI 建议仅供学习参考，最终过程评价和成绩由教师确认。

## Follow-up

- 对照原始数据复核公式、单位和有效数字，解释异常值的保留或剔除依据。
- 分析一种主要系统误差并提出可在实际装置上验证的改进。
