# 薄透镜焦距测量检查与纠错规则

## thin_lens_focal_length.step.1.rules

共轴与光屏调节

- 检查要点：固定物、凸透镜和光屏，使中心大致等高共轴；记录光具座刻度方向和长度单位

- 风险与易错点：不得用透镜直接观察太阳或强光源。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## thin_lens_focal_length.step.2.rules

共轭位置测量

- 检查要点：移动透镜或光屏获得最清晰实像；记录物、透镜和光屏的位置，改变共轭位置重复测量

- 风险与易错点：以最清晰位置为准，避免把模糊范围边缘当作成像位置。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## thin_lens_focal_length.step.3.rules

物距像距与焦距计算

- 检查要点：由相同刻度基准求 u、v 的正距离；逐组计算 f=uv/(u+v)，在表格保留各组数据和结果

- 风险与易错点：本表采用实物实像正距离约定，不适用于直接套算凹透镜。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## thin_lens_focal_length.step.4.rules

平均结果与方法讨论

- 检查要点：计算多组焦距均值，估计清晰成像判断与定位误差；说明薄透镜近似的影响，可在满足 L>4f 时采用位移法复核

- 风险与易错点：未满足位移法条件时不能强行寻找两个实像位置。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## thin_lens_focal_length.step.5.rules

实验结束与资料整理

- 检查要点：按现场规程停机或关闭光源、电源，将调节机构恢复安全位置；整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面

- 风险与易错点：先保存原始记录，不以计算结果覆盖原始读数；仪器复位以现场规程为准。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。
