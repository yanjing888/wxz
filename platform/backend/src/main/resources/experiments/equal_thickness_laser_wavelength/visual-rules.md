# 等厚干涉测量激光波长检查与纠错规则

## equal_thickness_laser_wavelength.step.1.rules

光路与方法确认

- 检查要点：确认采用迈克尔逊干涉仪及反射镜位移标定关系；调整两束光重合，并按设备规程获得可观察条纹

- 风险与易错点：禁止直视激光束或镜面反射光，不在未知光路中放置眼睛。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## equal_thickness_laser_wavelength.step.2.rules

等厚条纹与计数基准

- 检查要点：微调反射镜倾角，得到稳定的近似平行直条纹；设置固定计数参考线，沿单一方向预进微调机构以消除回程间隙

- 风险与易错点：条纹倾斜过大时近轴近似偏差增大，不以调节螺钉圈数代替已标定的镜面位移。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## equal_thickness_laser_wavelength.step.3.rules

条纹移动与位移记录

- 检查要点：缓慢单向移动反射镜，在固定参考线处累计条纹通过数；记录读数起点、终点及条纹数，重复多组并保留原始记录

- 风险与易错点：起止采用相同明暗判据，按间隔计数，避免把 N 条线误计为 N 个间隔。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## equal_thickness_laser_wavelength.step.4.rules

波长计算与误差分析

- 检查要点：将机构读数差换算为镜面实际位移 Δd；按 λ≈2；Δd；/N 求波长并换算为 nm，分析漏计、回程间隙和倾角误差

- 风险与易错点：此处 Δd 使用 μm 时，λ(nm)=2000|Δd(μm)|/N。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## equal_thickness_laser_wavelength.step.5.rules

实验结束与资料整理
