# 等厚干涉测量激光波长报告要求

## Knowledge

- 本版本暂按迈克尔逊干涉仪等厚条纹移动计数法组织：轻微倾斜等效反射面产生近似平行直条纹，在固定参考线处计数，反射镜沿光轴移动 Δd 时光程差近似改变 2Δd，近轴条件下 λ≈2|Δd|/N。必须使用镜面实际位移；若读数装置带传动倍率，应先按仪器标定换算。本方案不等同于空气劈尖测厚；实际装置不同需更换对应方法。
- 报告保留原始测量表格、单位、数据处理过程、重复测量结果和误差分析；说明实际采用的方法与仪器参数。
- AI 建议仅供学习参考，最终过程评价和成绩由教师确认。

## Follow-up

- 对照原始数据复核公式、单位和有效数字，解释异常值的保留或剔除依据。
- 分析一种主要系统误差并提出可在实际装置上验证的改进。
