# 油滴实验教学知识

## 实验原理

参考讲义：[哈尔滨工程大学物理实验中心：密立根油滴实验](https://pec.hrbeu.edu.cn/2023/0723/c13395a313775/page.htm)。具体参数及滑移修正采用现场仪器配套讲义。

采用静态平衡法：先由无电场时的匀速下落速度估计油滴半径，再由平衡电压确定电荷。无滑移近似 r = sqrt[9ηv/(2(ρ油−ρ空气)g)]，|q| = (4π/3)r³(ρ油−ρ空气)g d/|U|。微小油滴需按仪器讲义加入空气黏滞阻力滑移修正，不能将无修正结果当作精密结果；用多个油滴检验电荷近似为基本电荷的整数倍。

## millikan_oil_drop.step.1.teaching

观察系统与参数核对

- 核对极板间距、温度、油密度、空气黏度和标尺换算
- 调节目镜和照明，明确倒像时实际运动方向

## millikan_oil_drop.step.2.teaching

选择油滴与平衡调节

- 选择运动稳定且可持续跟踪的单颗油滴
- 调节电压使其悬浮，观察足够时间确认平衡

## millikan_oil_drop.step.3.teaching

无电场下落计时

- 关闭电场，待油滴进入匀速区后测量固定距离的下落时间
- 同一油滴重复计时并在表格保留每次距离、时间和平衡电压

## millikan_oil_drop.step.4.teaching

电荷计算与量子化检验

- 记录采用的黏度、密度、气压和滑移修正公式
- 计算各油滴电荷，比较多颗油滴的整数倍关系并分析不确定度

## millikan_oil_drop.step.5.teaching

实验结束与资料整理

- 按现场规程停机或关闭光源、电源，将调节机构恢复安全位置
- 整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面
