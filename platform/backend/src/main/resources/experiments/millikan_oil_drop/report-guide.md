# 油滴实验报告要求

## Knowledge

- 采用静态平衡法：先由无电场时的匀速下落速度估计油滴半径，再由平衡电压确定电荷。无滑移近似 r = sqrt[9ηv/(2(ρ油−ρ空气)g)]，|q| = (4π/3)r³(ρ油−ρ空气)g d/|U|。微小油滴需按仪器讲义加入空气黏滞阻力滑移修正，不能将无修正结果当作精密结果；用多个油滴检验电荷近似为基本电荷的整数倍。
- 报告保留原始测量表格、单位、数据处理过程、重复测量结果和误差分析；说明实际采用的方法与仪器参数。
- AI 建议仅供学习参考，最终过程评价和成绩由教师确认。

## Follow-up

- 对照原始数据复核公式、单位和有效数字，解释异常值的保留或剔除依据。
- 分析一种主要系统误差并提出可在实际装置上验证的改进。
