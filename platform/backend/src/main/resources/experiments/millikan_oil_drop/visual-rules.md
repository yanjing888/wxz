# 油滴实验检查与纠错规则

## millikan_oil_drop.step.1.rules

观察系统与参数核对

- 检查要点：核对极板间距、温度、油密度、空气黏度和标尺换算；调节目镜和照明，明确倒像时实际运动方向

- 风险与易错点：高压部分不得触碰，喷油及通断电按现场规程操作。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## millikan_oil_drop.step.2.rules

选择油滴与平衡调节

- 检查要点：选择运动稳定且可持续跟踪的单颗油滴；调节电压使其悬浮，观察足够时间确认平衡

- 风险与易错点：布朗运动明显、漂移或电荷突变的记录需说明并重新选滴。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## millikan_oil_drop.step.3.rules

无电场下落计时

- 检查要点：关闭电场，待油滴进入匀速区后测量固定距离的下落时间；同一油滴重复计时并在表格保留每次距离、时间和平衡电压

- 风险与易错点：计时期间跟踪同一油滴，不将视场距离直接当作真实距离。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## millikan_oil_drop.step.4.rules

电荷计算与量子化检验

- 检查要点：记录采用的黏度、密度、气压和滑移修正公式；计算各油滴电荷，比较多颗油滴的整数倍关系并分析不确定度

- 风险与易错点：不能预先指定整数电荷数再修改原始读数以吻合结论。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## millikan_oil_drop.step.5.rules

实验结束与资料整理

- 检查要点：按现场规程停机或关闭光源、电源，将调节机构恢复安全位置；整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面

- 风险与易错点：先保存原始记录，不以计算结果覆盖原始读数；仪器复位以现场规程为准。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。
