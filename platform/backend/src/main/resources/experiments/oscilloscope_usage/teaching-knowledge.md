# 示波器的使用实验教学知识

## 实验原理

学习示波器垂直、水平和触发系统。校准探头衰减设置后，Upp=竖直格数×每格电压×未被仪器计入的探头倍率；T=水平周期格数×每格时间，f=1/T。正弦波且去除直流分量时 Urms=Upp/(2√2)，非正弦波不能直接套用此关系。

## oscilloscope_usage.step.1.teaching

接地与探头检查

- 确认示波器地与被测电路地的关系，选择合适量程
- 匹配探头物理倍率与通道设置，使用校准信号检查补偿

## oscilloscope_usage.step.2.teaching

稳定显示与触发调节

- 接入低压信号，选择适当 AC/DC 耦合
- 调整时基、垂直档位、触发源、边沿和电平得到稳定波形

## oscilloscope_usage.step.3.teaching

幅值与周期测量

- 记录波形类型、探头倍率、各档位及跨周期读数
- 测量峰峰值与周期，并与光标或自动测量结果比较

## oscilloscope_usage.step.4.teaching

频率换算与读数分析

- 按 f(Hz)=1000/T(ms) 计算频率，与信号源设定值比较
- 分析触发不稳、采样不足、探头负载和读数分辨率影响

## oscilloscope_usage.step.5.teaching

实验结束与资料整理

- 按现场规程停机或关闭光源、电源，将调节机构恢复安全位置
- 整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面
