# 示波器的使用实验检查与纠错规则

## oscilloscope_usage.step.1.rules

接地与探头检查

- 检查要点：确认示波器地与被测电路地的关系，选择合适量程；匹配探头物理倍率与通道设置，使用校准信号检查补偿

- 风险与易错点：普通台式示波器地夹通常接保护地，禁止直接夹在市电火线上或浮地高电位点。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## oscilloscope_usage.step.2.rules

稳定显示与触发调节

- 检查要点：接入低压信号，选择适当 AC/DC 耦合；调整时基、垂直档位、触发源、边沿和电平得到稳定波形

- 风险与易错点：不能把 AC 耦合下消失的直流分量判断为原信号没有直流偏置。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## oscilloscope_usage.step.3.rules

幅值与周期测量

- 检查要点：记录波形类型、探头倍率、各档位及跨周期读数；测量峰峰值与周期，并与光标或自动测量结果比较

- 风险与易错点：如果仪器通道已经补偿探头倍率，不再重复乘倍率。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## oscilloscope_usage.step.4.rules

频率换算与读数分析

- 检查要点：按 f(Hz)=1000/T(ms) 计算频率，与信号源设定值比较；分析触发不稳、采样不足、探头负载和读数分辨率影响

- 风险与易错点：信号源设定值可能受 50Ω/高阻负载设置影响，比较前注明端接条件。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## oscilloscope_usage.step.5.rules

实验结束与资料整理

- 检查要点：按现场规程停机或关闭光源、电源，将调节机构恢复安全位置；整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面

- 风险与易错点：先保存原始记录，不以计算结果覆盖原始读数；仪器复位以现场规程为准。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。
