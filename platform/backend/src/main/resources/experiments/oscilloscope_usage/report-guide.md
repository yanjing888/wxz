# 示波器的使用实验报告要求

## Knowledge

- 学习示波器垂直、水平和触发系统。校准探头衰减设置后，Upp=竖直格数×每格电压×未被仪器计入的探头倍率；T=水平周期格数×每格时间，f=1/T。正弦波且去除直流分量时 Urms=Upp/(2√2)，非正弦波不能直接套用此关系。
- 报告保留原始测量表格、单位、数据处理过程、重复测量结果和误差分析；说明实际采用的方法与仪器参数。
- AI 建议仅供学习参考，最终过程评价和成绩由教师确认。

## Follow-up

- 对照原始数据复核公式、单位和有效数字，解释异常值的保留或剔除依据。
- 分析一种主要系统误差并提出可在实际装置上验证的改进。
