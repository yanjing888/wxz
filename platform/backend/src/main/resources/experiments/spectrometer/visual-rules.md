# 分光计实验检查与纠错规则

## spectrometer.step.1.rules

目镜与望远镜调节

- 检查要点：先调清叉丝，再用自准直方法调望远镜至无穷远；检查望远镜光轴与仪器转轴的关系

- 风险与易错点：调节动作轻缓，不触碰光学面或强拧限位机构。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## spectrometer.step.2.rules

平行光管与载物台调节

- 检查要点：调节平行光管使狭缝像清晰，采用适当狭缝宽度；调整载物台，使棱镜主截面与测角平面匹配

- 风险与易错点：不能用加宽狭缝掩盖离焦，棱镜轻放并保持清洁。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## spectrometer.step.3.rules

顶角与最小偏向位置测量

- 检查要点：用两反射面反射法等指定方法测顶角，分别保存两个游标原始读数；转动棱镜寻找谱线偏转的转折位置，测量最小偏向角并重复

- 风险与易错点：反射法两反射光线夹角为 2A；角差必须正确处理跨零点。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## spectrometer.step.4.rules

折射率与测角误差分析

- 检查要点：用实际光线夹角代入最小偏向角公式，计算前统一角度制；报告双游标平均方法、重复测量离散及谱线判读误差

- 风险与易错点：计算器的角度模式应与输入一致；顶角和偏向角均不能直接用单个刻盘读数代替。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## spectrometer.step.5.rules

实验结束与资料整理

- 检查要点：按现场规程停机或关闭光源、电源，将调节机构恢复安全位置；整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面

- 风险与易错点：先保存原始记录，不以计算结果覆盖原始读数；仪器复位以现场规程为准。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。
