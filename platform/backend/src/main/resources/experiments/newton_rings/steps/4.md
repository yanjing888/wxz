# 曲率半径计算

## Description

根据第 m 级与第 n 级暗环直径平方差，代入 R = (Dₘ² - Dₙ²) / [4(m - n)λ] 求平凸透镜曲率半径。

## Steps

- 根据各暗环左右两侧读数求出对应直径 Dₘ、Dₙ
- 逐组计算 Dₘ² - Dₙ²，并确认 |m-n| 不小于 5
- 取钠黄光波长 λ = 589.3 nm，统一单位后代入曲率半径公式
- 对多组 R 求平均值，必要时计算不确定度
- 分析读数、环心偏移、空程差、接触点变形等误差来源

## Warnings

- 注意 mm² 与 m 换算时的量级
- 多组数据可求平均，离群点应说明剔除理由
