# 声速测量实验检查与纠错规则

## sound_velocity.step.1.rules

换能器与信号检查

- 检查要点：使发射和接收换能器中心等高、轴线重合；连接信号源与示波器，低幅度起调并记录环境温度

- 风险与易错点：避免碰撞换能器端面，注意导轨活动范围。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## sound_velocity.step.2.rules

工作频率与稳定波形

- 检查要点：在换能器允许频段寻找稳定接收信号；记录实际工作频率和温度，保持后续测量频率不变

- 风险与易错点：不得将信号幅度增大当作替代对准或频率调节的方法。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## sound_velocity.step.3.rules

驻波极值位置记录

- 检查要点：沿同一方向逐个寻找同类幅度极值并记录位置；跨多个间隔测量，使用表格保存所有位置以便逐差处理

- 风险与易错点：N 个间隔对应 N+1 个同类极值位置；不混合峰与谷。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## sound_velocity.step.4.rules

声速与温度影响分析

- 检查要点：按 λ=2；Δx；/N 求波长，再由 v=fλ 求声速；记录重复结果并分析温度、对准、近场及极值定位的影响

- 风险与易错点：使用 kHz 与 mm 相乘恰得到 m/s；参考声速需注明温度和介质条件。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## sound_velocity.step.5.rules

实验结束与资料整理

- 检查要点：按现场规程停机或关闭光源、电源，将调节机构恢复安全位置；整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面

- 风险与易错点：先保存原始记录，不以计算结果覆盖原始读数；仪器复位以现场规程为准。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。
