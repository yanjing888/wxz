# 声速测量实验报告要求

## Knowledge

- 本版本采用超声驻波法：发射与接收换能器频率相同，沿轴移动接收端，相邻同类幅度极值位置相距约 λ/2。跨 N 个极值间隔的距离 Δx 对应 λ=2|Δx|/N，v=fλ。可用相位法复核，但同相重复点间距为 λ，不能与驻波极值间距混用。
- 报告保留原始测量表格、单位、数据处理过程、重复测量结果和误差分析；说明实际采用的方法与仪器参数。
- AI 建议仅供学习参考，最终过程评价和成绩由教师确认。

## Follow-up

- 对照原始数据复核公式、单位和有效数字，解释异常值的保留或剔除依据。
- 分析一种主要系统误差并提出可在实际装置上验证的改进。
