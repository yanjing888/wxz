# 霍尔效应实验教学知识

## 实验原理

载流薄片在垂直磁场中产生横向霍尔电压。理想单载流子模型下 U_H = R_H I B / d；保持样品电流不变拟合 U_H–B，或保持 B 不变拟合 U_H–I。R_H 的符号必须结合电流、磁场和电压引线方向判断；仅在单载流子近似下用 n = 1/(|e R_H|) 估算载流子浓度。

## hall_effect.step.1.teaching

样品与接线检查

- 识别样品电流端、霍尔电压端和励磁回路
- 断电核对接线、样品厚度及量程，记录磁场标定方法

## hall_effect.step.2.teaching

零点与磁场标定

- 在规定工作范围内检查电压零点
- 记录样品厚度并按特斯拉计或仪器标定关系确定磁感应强度

## hall_effect.step.3.teaching

换向测量与原始记录

- 固定电流和磁场大小，分别改变两者方向
- 记录 U(+I,+B)、U(−I,+B)、U(−I,−B)、U(+I,−B)，在表格保留多组原始值

## hall_effect.step.4.teaching

霍尔系数与误差分析

- 按既定接线方向用四次换向组合消除偶对称偏置
- 计算 U_H=(Upp−Unp+Unn−Upn)/4，统一 SI 单位求 R_H，分析拟合与零点误差

## hall_effect.step.5.teaching

实验结束与资料整理

- 按现场规程停机或关闭光源、电源，将调节机构恢复安全位置
- 整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面
