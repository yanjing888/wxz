# 霍尔效应实验检查与纠错规则

## hall_effect.step.1.rules

样品与接线检查

- 检查要点：识别样品电流端、霍尔电压端和励磁回路；断电核对接线、样品厚度及量程，记录磁场标定方法

- 风险与易错点：不得将励磁电源接入霍尔电压端；电流上限以实际仪器说明为准。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## hall_effect.step.2.rules

零点与磁场标定

- 检查要点：在规定工作范围内检查电压零点；记录样品厚度并按特斯拉计或仪器标定关系确定磁感应强度

- 风险与易错点：励磁电流不能直接当作磁感应强度。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## hall_effect.step.3.rules

换向测量与原始记录

- 检查要点：固定电流和磁场大小，分别改变两者方向；记录 U(+I,+B)、U(−I,+B)、U(−I,−B)、U(+I,−B)，在表格保留多组原始值

- 风险与易错点：每次换向先按设备要求降流或断电，稳定后读数。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## hall_effect.step.4.rules

霍尔系数与误差分析

- 检查要点：按既定接线方向用四次换向组合消除偶对称偏置；计算 U_H=(Upp−Unp+Unn−Upn)/4，统一 SI 单位求 R_H，分析拟合与零点误差

- 风险与易错点：不得只凭单次电压正负判断载流子类型。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## hall_effect.step.5.rules

实验结束与资料整理

- 检查要点：按现场规程停机或关闭光源、电源，将调节机构恢复安全位置；整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面

- 风险与易错点：先保存原始记录，不以计算结果覆盖原始读数；仪器复位以现场规程为准。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。
