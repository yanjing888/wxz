# 霍尔效应实验报告要求

## Knowledge

- 载流薄片在垂直磁场中产生横向霍尔电压。理想单载流子模型下 U_H = R_H I B / d；保持样品电流不变拟合 U_H–B，或保持 B 不变拟合 U_H–I。R_H 的符号必须结合电流、磁场和电压引线方向判断；仅在单载流子近似下用 n = 1/(|e R_H|) 估算载流子浓度。
- 报告保留原始测量表格、单位、数据处理过程、重复测量结果和误差分析；说明实际采用的方法与仪器参数。
- AI 建议仅供学习参考，最终过程评价和成绩由教师确认。

## Follow-up

- 对照原始数据复核公式、单位和有效数字，解释异常值的保留或剔除依据。
- 分析一种主要系统误差并提出可在实际装置上验证的改进。
