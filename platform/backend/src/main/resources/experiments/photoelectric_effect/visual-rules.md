# 光电效应实验检查与纠错规则

## photoelectric_effect.step.1.rules

光电管与暗电流检查

- 检查要点：核对光电管供电、微电流量程和滤光片波长；遮光检查暗电流及零点，按现场要求预热

- 风险与易错点：光电管避免强光长时间照射，断电后再更改接线。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## photoelectric_effect.step.2.rules

单色光与伏安特性

- 检查要点：选择已知波长的滤光片并固定照明几何关系；按仪器规程扫描电压，记录电压、电流和暗电流，形成伏安曲线

- 风险与易错点：不超过光电管允许电压；更换滤光片后等待读数稳定。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## photoelectric_effect.step.3.rules

不同频率截止电压测量

- 检查要点：使用一致且有说明的截止判据，结合暗电流确定截止位置；更换多种波长重复测量，表格记录波长、截止电压及不确定度

- 风险与易错点：截止电压表记录大小；不能将仪器电压符号直接当作其大小。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## photoelectric_effect.step.4.rules

普朗克常量拟合与讨论

- 检查要点：将波长换算为频率，对 U_stop–ν 进行多点线性拟合；由 h=e×斜率求普朗克常量，讨论截距、接触电势和照度影响

- 风险与易错点：一个频率点不足以同时确定斜率和截距，不预设拟合必须通过原点。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## photoelectric_effect.step.5.rules

实验结束与资料整理

- 检查要点：按现场规程停机或关闭光源、电源，将调节机构恢复安全位置；整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面

- 风险与易错点：先保存原始记录，不以计算结果覆盖原始读数；仪器复位以现场规程为准。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。
