# 滑线变阻器特性研究检查与纠错规则

## slide_wire_resistor.step.1.rules

端子识别与额定值检查

- 检查要点：断电用电阻挡识别两个固定端和滑片端；记录总阻值、额定电流及电源范围

- 风险与易错点：禁止带电测电阻，避免滑片短接电源。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## slide_wire_resistor.step.2.rules

限流电路测量

- 检查要点：按限流接法接线，通电前将接入阻值调至最大；逐步移动滑片，逐点记录位置、电压和电流

- 风险与易错点：不超过变阻器局部电阻丝、电流表和负载额定值。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## slide_wire_resistor.step.3.rules

空载与带载分压测量

- 检查要点：断电改接分压电路，输出从低电压开始；在相同滑片位置分别测量空载与接入负载后的输出，保留多组表格

- 风险与易错点：空载指未接被测负载，电压表的有限输入电阻仍可能影响结果。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## slide_wire_resistor.step.4.rules

特性曲线与接法比较

- 检查要点：绘制位置–接入电阻、位置–输出电压曲线；解释负载效应，比较限流与分压接法的调节范围和功耗

- 风险与易错点：不能将空载线性规律直接套用于任意带载电路。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。

## slide_wire_resistor.step.5.rules

实验结束与资料整理

- 检查要点：按现场规程停机或关闭光源、电源，将调节机构恢复安全位置；整理原始记录、数据表格和过程照片，检查报告所需信息并清理台面

- 风险与易错点：先保存原始记录，不以计算结果覆盖原始读数；仪器复位以现场规程为准。

- 判断边界：仅根据学生提供的图像和读数分析；看不清接线、刻度或状态时要求补充证据，不声称已确认仪器安全或操作正确。
