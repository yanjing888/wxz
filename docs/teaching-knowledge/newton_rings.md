# 牛顿环法测定平凸透镜曲率半径教学知识库

本文档用于 Dify 的“实验教学知识库”。它面向原理讲解、步骤指导、数据处理、报告生成和学习建议；不承担视觉判错规则职责。视觉纠错规则请使用 `docs/visual-rules/newton_rings.md`。

## 一、实验目的

1. 观察等厚干涉现象，理解牛顿环的形成条件。
2. 掌握读数显微镜观察和测量干涉环直径的方法。
3. 通过测量多级暗环直径，计算平凸透镜的曲率半径。
4. 训练单向逼近读数、重复测量、单位换算和误差分析能力。

## 二、实验原理

牛顿环是由平凸透镜和平玻璃板之间形成的空气薄膜产生的等厚干涉现象。当单色光垂直入射时，空气膜上下表面的反射光发生干涉，形成一系列以接触点为中心的同心明暗圆环。

对反射光暗环，常用关系为：

```text
r_m^2 = m λ R
D_m^2 = 4 m λ R
```

其中：

- `r_m`：第 m 级暗环半径；
- `D_m`：第 m 级暗环直径；
- `λ`：单色光波长；
- `R`：平凸透镜曲率半径；
- `m`：暗环级数。

为了减小环心定位误差，实验中常使用两条暗环直径平方差：

```text
D_m^2 - D_n^2 = 4 (m - n) λ R
```

若已知波长 `λ`，可求曲率半径：

```text
R = (D_m^2 - D_n^2) / [4 (m - n) λ]
```

若已知曲率半径 `R`，可求波长：

```text
λ = (D_m^2 - D_n^2) / [4 (m - n) R]
```

## 三、仪器与材料

常见仪器包括：

- 牛顿环仪；
- 平凸透镜和平玻璃板；
- 读数显微镜；
- 钠光灯或其他单色光源；
- 45° 可调半反镜组；
- MKS-NHY 示教 CCD 系统；
- 数据记录表或采集终端。

## 四、实验步骤

### Step 1：仪器摆放与光路装调

目标：将 JCD-3 读数显微镜、牛顿环组件、钠光灯和 45° 半反镜组成正确光路。

操作要点：

1. 将读数显微镜平稳放置，把牛顿环器件置于工作台并用压片压紧。
2. 移动器件，使牛顿环中心接触点大致位于物镜正下方。
3. 将底座下方反光镜向内翻转收起，避免杂散光。
4. 安装 45° 半反镜组，使钠光灯从侧面照射半反镜。
5. 如使用示教系统，安装固定座、连接杆、变焦镜头与 CCD 摄像机。

### Step 2：目镜视度调节与粗调成像

目标：先调清十字分划板，再由低向高抬升镜筒寻找清晰、均匀的牛顿环图样。

操作要点：

1. 旋转目镜，让十字分划板或叉丝清晰。
2. 缓慢转动调焦手轮，使镜筒自下向上抬升。
3. 微调 45° 半反镜角度，使单色光近似垂直向下入射。
4. 平移工作台，把中心暗斑调整到视场中央附近。

### Step 3：暗环直径测量

目标：沿圆环直径方向移动显微镜，测量同一级暗环左右两侧位置差，得到暗环直径。

推荐记录字段：

```text
暗环级数 m/n
左读数 reading_left_mm
右读数 reading_right_mm
直径 D_m = |reading_right_mm - reading_left_mm|
```

操作要点：

1. 确认测量的是直径而不是弦长，移动方向应穿过环心。
2. 选择两组环序差较大的暗环，一般使 |m-n| ≥ 5。
3. 先在中心左侧越过最高级待测暗环若干圈，以消除齿轮间隙。
4. 左侧按 m、m-1、...、n 记录，右侧按 n、...、m-1、m 记录。
5. 同一级暗环右侧读数与左侧读数之差即为直径 D。

### Step 4：曲率半径计算

目标：根据 `D_m^2 - D_n^2` 与环序差 `|m-n|` 计算平凸透镜曲率半径。

操作要点：

1. 计算每组暗环直径平方。
2. 计算 `D_m^2 - D_n^2`。
3. 取钠黄光波长 λ = 589.3 nm。
4. 统一单位后代入 R = (D_m^2 - D_n^2) / [4(m - n)λ]。
5. 对多组 R 求平均值，必要时计算不确定度。

### Step 5：实验结束整理

目标：关闭光源和示教设备，取下牛顿环器件并恢复实验台。

操作要点：

1. 关闭钠光灯、监视器与 CCD 电源。
2. 取下牛顿环器件，盖好镜头盖。
3. 整理线缆和附件，使仪器恢复原位。

## 五、数据处理规范

### 直径计算

```text
D_m = |右读数 - 左读数|
```

注意：

- 左右读数必须属于同一暗环；
- 单位通常为 mm；
- 有效数字应与仪器分辨率匹配。

### 平方差计算

```text
D_m^2 - D_n^2
```

注意：

- 若 D 使用 mm，则 D² 单位是 mm²；
- 代入公式前要确认 λ 和 R 的单位与 D² 匹配。

### 常见波长参考

钠光波长约：

```text
λ ≈ 589.3 nm
```

## 六、常见误差来源

1. 环心定位不准导致系统误差。
2. 环纹模糊导致判线不一致。
3. 鼓轮回程误差导致读数偏差。
4. 左右读数选取了不同暗环。
5. 透镜或玻璃表面污染导致环纹畸变。
6. 单位换算错误导致结果数量级异常。
7. 有效数字保留不规范。
