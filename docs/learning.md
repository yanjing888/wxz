# 我的学习与学习统计

学生端新增“我的学习”，教师端统一从“学情分析”进入。左侧菜单为“学情总览”和“学习统计”，右侧切换对应页面。沿用既有教学班、任务、仿真、实验会话、正式数据和教师批阅记录；统计由后端计算，前端不提交积分或能力分。

## 学生使用

- 待办任务：当前实验、已完成实操但待交的报告、已批阅但尚未订正当前反馈的报告。
- 反馈订正：查看教师已发布的成绩和评语，填写订正内容并提交，支持修改。订正单独存储，不覆盖原报告或教师评语。
- 实验记录：按任务分配顺序汇总实验状态、完成时间和积分。排队任务遵循原有实验顺序，不新增绕过入口。
- 积分明细：查看每个实验已经获得的各项积分。
- 能力雷达：显示个人五项学习指标，缺失数据为 `—`，不使用默认高分填充图形。
- 班级排行：可切换本人所属教学班。排名仅计算该班分配的任务；个人总积分汇总自己的全部已分配任务，因此多班学生的个人总积分可以与单班排行积分不同。

## 教师使用

进入“学情分析”，顶部的实验选择对“学情总览”和“学习统计”均生效。左侧选择“学情总览”查看当前实验的学生进度、报告提交/批阅状态和详情，选择“学习统计”查看所选实验的班级统计。两个菜单分别保留原有筛选和操作，不同时挤在一个页面中。

在“学习统计”选择可管理教学班，查看班级人数、已获积分人数、平均积分、最高积分、能力指标均值和班级排行。支持按姓名、学号搜索及查看学生明细，包括实验积分来源、教师评语和学生订正。跨班学生的明细只显示当前班分配的任务和对应班级实验记录。

教师页面传入 `experimentCode` 后，仅统计该班分配了所选实验的学生；积分、能力指标及个人详情均限定为同一实验。切换实验会清空旧列表并重新加载，已打开的详情会关闭。接口不传 `experimentCode` 时保留累计统计，学生端的个人总积分和班级排行继续汇总全部已分配实验。

## 积分规则

| 每个实验的环节 | 积分 |
| --- | --- |
| 完成仿真或预习 | 10，两者完成不叠加 |
| 至少完成一次实物实验 | 20 |
| 至少记录一次正式数据 | 10，过程检查不计入 |
| 提交报告 | 20 |
| 提交当前教师反馈的订正 | 10 |
| 教师确认成绩 | 百分制成绩 × 0.3，四舍五入，最高30 |

同一实验最高100分，无正式数据环节的实验可能不取得数据项积分。重复实验、重复提交或修改订正不重复计分。积分是当前有效记录的聚合结果，不是可以累加消费的积分账户；成绩调整、反馈更新或移除分配后会重新计算。AI预评不参与积分和报告均分，不对求助、看教程扣分。积分为0时不排名，同分使用竞赛排名，例如1、1、3。

## 能力指标

这些指标用于反映学习记录，不替代教师对学生实验能力的评价。

| 维度 | 计算方式 |
| --- | --- |
| 实验准备 | 完成仿真或预习的实验数 / 已分配实验数 × 100 |
| 实验完成 | 完成实物实验的实验数 / 已分配实验数 × 100 |
| 数据质量 | 每个实验步骤最新的正式数据中，`validationJson.ok` 明确为真占明确布尔校验结果的比例；缺失或无法解析的校验不计入 |
| 报告质量 | 已正式提交、已确认批阅报告的教师百分制成绩均值 |
| 反馈订正 | 已提交当前反馈订正的报告数 / 已批阅报告数 × 100 |

班级雷达逐项计算有记录学生的均值，缺失维度不按0分填充。教师修改成绩或评语后，反馈版本变化，旧订正内容保留但标记为待更新，不获得当前反馈订正的10分；再次提交后恢复。提交时核验反馈版本，过期页面收到409并提示刷新。

## 数据与部署

仅新增 `learning_reflections` 表，按学生和实验唯一保存订正、教师反馈版本与提交时间。任务、成绩和积分来源继续使用现有表；没有修改历史成绩或批量创建演示数据。

当前 `spring.jpa.hibernate.ddl-auto=update` 会在后端启动时创建新表。禁止自动建表的环境请备份后审查并执行 `config/lab-schema-migration.sql` 中对应建表语句。本功能不需要新增环境变量、IP或外部服务配置。

学生页面 `/learning` 支持直接访问和刷新，正式包继续通过同一JAR部署。接口：`GET /api/student/learning`、`PUT /api/student/learning/{code}/reflection`、`GET /api/teacher/learning`、`GET /api/teacher/learning/students/{id}`。所有接口校验启用状态与角色，学生不能提交其他学生ID，教师明细强制校验教学班范围。

检查命令：`npm --prefix frontend run test:learning`、`mvn -q test`（backend目录）、`npm --prefix frontend run build`。
