# 物小智真实实验教学流程评估

评估日期：2026-10-16。依据当前项目实现，以及“一个实验项目在固定实验室开展”的部署场景。

## 判断

目前具备学生导入、实验分配、仿真预习、实操引导、数据记录、报告提交和教师批改，适合单实验流程试用；尚不能认为完整覆盖正式课堂。最需要补齐的是“学生何时到哪个实验室、使用哪套设备、由谁验收”。

以下分为本次已调整的页面与后续建议。后续建议尚未实现，不能作为已有功能对外描述。

## 本次页面调整

- 保留原有页面框架、顶部 Tab 图标、颜色及排列。
- 学情默认展示教师权限范围内全部班级，按班级分组；没有分配当前实验的班级明确显示“本实验未分配学生”，不计为缺交或未开始。
- 学生管理默认展示全部班级全部学生，包括尚未分配当前实验的学生；同一账号在不同班级分别显示成员记录，不创建重复账号。
- 学情、学生管理、报告列表分别搜索班级、学号或姓名，搜索互不影响；取消顶部共用班级条件与旧班级记忆。
- 学生管理精简说明，分配设置折叠，保留步骤预览、补充要求和报告截止时间。
- 批量选择按“班级＋账号”识别，按班级分别提交分配。同一账号同时跨班选中会提示处理；已有记录不被静默迁移到新班级。

## 实验步骤如何维护

建议采用“内置标准模板＋实验室仪器版本＋教师课次补充要求”。任课教师无需为每个班从头编写标准步骤。

1. 标准模板：实验目的、原理、操作步骤、数据表、单位、计算规则、误差分析和检查点，由实验负责人维护。
2. 仪器版本：同一个牛顿环实验，不同型号仪器的调焦、读数和光路操作可能不同；应绑定实验室实际设备型号及仿真资源。
3. 课次要求：任课教师配置测量次数、选做内容、分组方式、报告期限和评分要求；不直接改变物理公式及标准数据字段。
4. 发布版本：教学负责人审核后发布；已开始课次保存模板版本快照，后续修改不覆盖学生旧数据和已批改报告。

当前已有内置步骤和分配补充要求；尚无完整模板编辑、审核及版本快照机制。

## 实验室组织关系

在目前固定实验室场景中，建议按以下关系管理，而不是只保存“账号＋实验代码”：

```text
实验教学中心
  └─ 实验室（绑定实验项目、仪器版本）
       ├─ 工位（真实仪器、CCD/示教设备、摄像头）
       └─ 教学课次（学期、日期时段、教师、容量）
            └─ 学生名单 / 小组 → 实操记录 → 验收 → 个人报告
```

行政班是学生身份信息；教学班是课程成员关系；课次是一次实际上课安排。学生跨班补做不等于复制账号，也不应覆盖原班已有成绩。

即使当前每个实验项目只有一个实验室，也应保留独立实验室标识，以区分地点、设备配置和负责人；将来有两间牛顿环实验室时无需重构全部记录。

## 优先补齐的业务

| 优先级 | 当前缺口及证据 | 建议行为 |
| --- | --- | --- |
| P0 | 当前任务按分配时间排序，缺少课次、时段、地点模型 | 以课表或教师开课安排决定当次实操；学生可提前预习已发布的后续实验，同时只保留一场进行中的真实实操 |
| P0 | 分配按“用户＋实验代码”唯一，同一实验跨班重复分配被拒绝 | 新增教学任务/课次标识；区分正常上课、补做与重修，避免用旧完成状态挡住新课次 |
| P0 | 实操结束接口直接写 FINISHED，没有教师验收状态 | 学生提交验收，教师核对原始数据、仪器状态后确认；不合格退回继续操作，保存验收人和时间 |
| P0 | 摄像头卡片按学生生成并共用统一流地址，工位名称来自列表序号 | 工位和摄像头固定绑定；课次签到时分配学生/小组到工位，监控按真实工位展示，不能用学生列表顺序推断工位 |
| P1 | 没有到课、缺席、请假、调课和补做状态 | 绑定课次签到；缺席和未分配分开统计，教师可安排补做，保留原记录 |
| P1 | 报告提交后只读，没有退回重交版本 | 增加退回原因、重交期限、版本与批改记录；重交不能静默覆盖旧评分 |
| P1 | 现有报告评分不能完整表示课堂操作评价 | 分别记录预习、操作、报告成绩，权重按课程配置；AI 给建议，教师确认最终成绩 |
| P1 | 多人共用仪器时缺少明确小组归属 | 工位可绑定小组；按课程决定原始数据是否共享，报告及成绩仍按个人保存 |
| P1 | 教师权限目前主要依赖管理班级，尚无实验室/课次权限 | 实验室负责人管理模板和设备，任课教师管理负责课次；跨班验收和批改需有明确授权 |

P0 中的验收不是用聊天轮数、步骤按钮点击或 AI 判断代替教师到场确认。AI 可提示数据异常和漏项，但这些记录本身不能证明学生已完成物理操作。

## 推荐课堂流程

```text
发布课次与名单
  → 课前预习、仿真、测验
  → 到实验室签到并绑定工位/小组
  → 教师确认准入，开始实操
  → 记录原始数据，必要时向智能体或教师求助
  → 提交验收；未通过则继续操作
  → 教师验收数据及仪器复位，确认实操结束
  → 学生课后完成并提交个人报告
  → AI 辅助预评，教师批改；需要时退回重交
  → 确认成绩，归档
```

实操验收通过后即可参加后续课次，旧报告未提交不应锁死所有新实验，但应在报告列表持续提醒。报告截止时间、逾期处理和预习合格线由课程规定，不能把某一所学校的规则写死。

物小智可以对接已有教务课表及签到系统，不必重新建设整套教务系统。即使由外部系统排课，物小智仍需保存课次标识、地点、工位及验收记录，才能正确关联课堂操作、图像、报告和成绩。

- [大连理工大学：大学物理实验](https://phyedu.dlut.edu.cn/jbwz/virlab/sykc/dxwlsy.htm)：基础实验与综合、设计及探索实验分层，预习涉及原理、仪器和数据表，数据经教师检查后整理仪器。
