# 起终点读数

## Description

让竖叉丝依次对准被测长度起点和终点，读取 A 与 A′，并计算 L = A′ - A。

## Steps

- 单向转动测微鼓轮，使竖叉丝对准被测起点，记录读数 A
- 保持鼓轮转向不变，移动到被测终点并使竖叉丝对准终点
- 记录终点读数 A′
- 计算被测长度 L = A′ - A
- 读数时主尺读整数毫米，测微鼓轮读小数部分

## Warnings

- 每次测量鼓轮应单向旋转，避免空程差
- 鼓轮最小刻度为 0.01 mm，实验中可按要求估读到 0.001 mm
- 若读数方向反向，应同向多转后重新对准
