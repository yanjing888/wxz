# 暗环直径测量

## Description

沿圆环直径方向移动显微镜，使竖叉丝依次与同级暗环左右两侧相切，读取位置差得到暗环直径。

## Steps

- 确认测量的是直径而不是弦长，显微镜移动方向应穿过环心
- 选择两组环序数差较大的暗环，一般使 |m-n| ≥ 5
- 向同一方向旋转测微鼓轮，先越过最高级待测暗环若干圈以消除齿轮间隙
- 继续同向转动，使竖叉丝依次与第 m、m-1、...、n 级暗环左侧相切并记录读数
- 不反转鼓轮，跨过中心到达右侧，再按 n、...、m-1、m 的顺序记录同级暗环右侧读数
- 同一级暗环右侧读数与左侧读数之差即为该级暗环直径 D

## Warnings

- 鼓轮必须单向逼近读数，消除空程误差
- 不把中心暗斑当作测量环，避开磨损、畸变或不完整的圆环
- 鼓轮最小分度为 0.01 mm，读数时主尺整数和鼓轮小数都要记录
