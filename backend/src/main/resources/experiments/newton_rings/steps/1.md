# 仪器摆放与光路装调

## Description

将 JCD-3 读数显微镜、牛顿环组件、钠光灯与 45° 半反镜组成正确光路，为后续观察等厚干涉环纹做准备。

## Steps

- 将读数显微镜平稳放置，把牛顿环器件置于工作台上并用压片压紧
- 肉眼观察并移动器件，使牛顿环中心接触点大致位于物镜正下方
- 旋转底座下方反光镜的旋轮，使反光镜向内翻转收起，避免杂散光进入视场
- 在物镜组上安装可调式 45° 半反镜组，将钠光灯水平放在半反镜侧面
- 如使用示教系统，安装固定座、连接杆、变焦镜头与 CCD 摄像机，并接好 HDMI 线和 12V 电源

## Warnings

- 不要触摸平凸透镜和平板玻璃的光学表面
- 不要随意拧动牛顿环装置上的压紧螺丝
- CCD 镜头到目镜出光面距离以约 5-7 mm 为宜
