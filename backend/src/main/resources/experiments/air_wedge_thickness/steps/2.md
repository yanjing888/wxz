# 调焦与条纹校正

## Description

调清叉丝和劈尖干涉条纹，并通过劈尖夹座让条纹方向与水平叉丝平行。

## Steps

- 先调节目镜视度，使十字叉丝清晰
- 转动调焦手轮，使镜筒向上抬升，直到视场中出现平行直干涉条纹
- 若条纹相对水平叉丝倾斜，调节劈尖夹座上的四颗固定螺钉
- 微调 45° 半反镜角度，使整个视场内条纹亮度尽量均匀
- 记住空气劈尖条纹可能略显虚化，这是仪器观察中的正常现象

## Warnings

- 条纹偏斜时调劈尖夹座，不要旋转显微镜本体
- 不必因条纹略虚而反复大幅度调焦
- 调焦时镜筒应由低向高移动
