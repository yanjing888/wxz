# 器件安放与光路调节

## Description

取下牛顿环组件，放上空气劈尖装置，使用钠光灯和 45° 半反镜形成观察劈尖干涉条纹的光路。

## Steps

- 从工作台上取下牛顿环组件，放上空气劈尖装置，并用压片压稳
- 肉眼观察并调整劈尖，使劈尖棱边大致与显微镜叉丝水平方向平行
- 继续使用 45° 半反镜组，钠光灯从侧向照射半反镜
- 将底座反光镜向内收起，减少底部杂散光
- 若使用示教系统，开启 CCD 与监视器，确认画面正常

## Warnings

- 压片只需压稳，不要用力过大
- 不要触碰劈尖玻璃表面
- 底座反光镜应向内翻转收起
