# 测量数据采集

## Description

记录选定条纹区间的起终点读数、条纹数，以及劈尖棱边到薄片位置的距离。

## Steps

- 转动测微鼓轮，在清晰条纹区域记录区间起点读数 x₁ 和终点读数 x₂
- 计算 L′ = |x₂ - x₁|
- 在该区间内数出暗纹或明纹的条纹数 n′，全程只选一种条纹
- 移动显微镜到劈尖棱边位置，读取棱边读数 x棱
- 继续移动到薄片所在位置，读取薄片位置读数 x片，并计算 L = |x片 - x棱|
- 重复测量 5 次，获得多组 L、L′ 和 n′

## Warnings

- 起点、终点落在条纹中间时，不把该条纹计入 n′
- 全部移动和读数保持测微鼓轮同一转向
- 棱边和薄片边缘模糊时，可选条纹刚消失或变化明显的位置作为读数标记
